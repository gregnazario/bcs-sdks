## [1.0.0] - 2026-01-27

### Added

- Initial release of BCS Python SDK
- Full BCS serialization and deserialization support
- Support for all BCS types: bool, integers (u8-u128, i8-i128), f32, f64
- Variable-length sequences and fixed-length arrays
- Optional values and maps
- ULEB128 encoding for lengths
- Comprehensive test suite with test vectors
